## ✨ About the Project

**RIVOK** is a web-based image and video resizing application built using Python and Flask.

It allows users to upload media, choose resizing dimensions, and process their files through a clean and elegant interface.

The project combines functionality with a luxury-inspired visual design featuring a burgundy and pink colour palette, animated butterflies, shimmer effects, and modern typography.

## 🚀 Features

- 🖼️ **Image Resizing** – Resize images according to selected dimensions.
- 🎬 **Video Resizing** – Process and resize video files.
- 📐 **Custom Dimensions** – Enter your preferred width and height.
- ⚙️ **Resize Presets** – Choose from predefined resizing options.
- 📥 **File Download** – Download the processed result.
- 🦋 **Elegant Interface** – Luxury-inspired design with animated butterflies and visual effects.
- 📱 **Responsive Design** – User-friendly layout across different screen sizes.

## 💻 Installation and Setup

Follow these steps to run RIVOK locally.

### 1. Clone the Repository

```bash
git clone https://github.com/dilpreet15857/RIVOK-Resizer.git
```

### 2. Navigate to the Project Folder

```bash
cd RIVOK-Resizer
```

### 3. Create a Virtual Environment

```bash
py -m venv venv
```

### 4. Activate the Virtual Environment

For Windows PowerShell:

```powershell
.\venv\Scripts\Activate.ps1
```

### 5. Install Dependencies

```bash
pip install -r requirements.txt
```

### 6. Run the Application

```bash
py app.py
```

### 7. Open in Your Browser

Visit:

```text
http://127.0.0.1:5000
```

Enjoy using RIVOK!
